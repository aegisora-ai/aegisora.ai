# Roadmap

Aegisora is building the open runtime governance platform for autonomous AI systems.

This roadmap represents our long-term direction. Priorities may evolve based on community feedback, research, and security needs.

---

# Vision

Our long-term goal is to become the standard runtime security and governance layer for AI agents.

---

# Version 0.1 — Foundation

## Goal

Build a solid open-source foundation.

### Planned

- Project architecture
- Documentation
- Website
- Governance
- Security policy
- Contributor experience
- CI/CD
- Initial policy engine
- Runtime gateway

Status: 🚧 In Progress
